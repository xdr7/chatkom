# ChatKom - Aplikasi Chat Modern

![ChatKom Logo](assets/img/logo.png)

**ChatKom** adalah aplikasi chat modern berbasis PHP dengan fitur lengkap. Dibuat oleh **Sasskom.app**.

## ✨ Fitur Utama

- 💬 **Real-time Chat** - Kirim dan terima pesan secara instan
- 📁 **File & Image Upload** - Kirim gambar dan berbagai jenis file
- 😊 **Emoji Support** - Ekspresikan diri dengan ribuan emoji
- 📱 **Mobile Responsive** - Tampilan optimal di semua perangkat
- 🔐 **Secure Authentication** - Login dan register dengan enkripsi
- 👑 **Superadmin Panel** - Kelola pengguna, pesan, dan pengaturan
- 👥 **Friend System** - Tambah dan kelola teman
- 🌙 **Dark Mode** - Tema gelap yang nyaman di mata
- 🔔 **Notifications** - Notifikasi pesan dan permintaan teman

## 🛠️ Teknologi

- **Backend**: PHP 7.4+
- **Database**: MySQL 5.7+
- **Frontend**: HTML5, CSS3, JavaScript
- **Icons**: Font Awesome 6
- **Real-time**: AJAX Polling

## 📦 Requirements

- PHP 7.4 atau lebih tinggi
- MySQL 5.7 atau MariaDB 10.2+
- Apache/Nginx web server
- PHP Extensions: PDO, MySQLi, GD, FileInfo, JSON
